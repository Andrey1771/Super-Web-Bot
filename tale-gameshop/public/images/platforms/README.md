# Фото-арты карточек платформ (главная, ряд под каруселью)

Сюда кладутся PNG-вырезки с прозрачным фоном (в сборку копируется всё, кроме `*.md`):

| Файл           | Карточка              | Что на нём                              |
| -------------- | --------------------- | --------------------------------------- |
| `keyboard.png` | Explore PC Games      | игровая клавиатура                      |
| `gamepad.png`  | Explore Console Games | геймпад (PlayStation & Xbox)            |
| `software.png` | Software & Utilities  | коллаж приложений/утилит                |

Рекомендации:
- прозрачный фон (PNG/WebP-вырезка, без белой подложки);
- ширина от ~500px — в карточке арт показывается высотой ~80px, но на retina нужен запас;
- предмет целиком, без обрезанных краёв: вписывается через `object-fit: contain`.

Пока файла нет, карточка автоматически показывает векторный фолбэк
(`HeroCategoryCard`, tale-gameshop-main-page.tsx) — ничего не сломается.
