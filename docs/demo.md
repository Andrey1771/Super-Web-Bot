# Демо-сайт для портфолио

Отдельная установка магазина, которую можно дать «потрогать» клиентам: всё работает по-настоящему, но ничего не
выходит наружу и никто не может испортить сайт другим.

## Как устроено

- **Своя копия на сутки.** Посетитель нажимает «Открыть свою копию» и получает копию базы-шаблона на 24 часа:
  меняет цены, добавляет игры и DLC, покупает, смотрит отчёты. Его изменения видит только он; «Начать заново»
  выдаёт свежую копию. Копии собираются заранее (2 про запас), поэтому выдача мгновенная. Не больше
  `DEMO_MAX_SANDBOXES` копий сразу (10) и 3 в сутки с одного адреса; истёкшие удаляются сами.
  Код: `SuperBot.WebApi/Demo`, `SuperBot.Core/Demo`, фронт — `tale-gameshop/src/features/demo`.
- **Без своей копии** сайт можно только смотреть: любое изменение предлагает открыть копию.
- **Только просмотр и в копии** — то, что изменило бы сайт для всех: пароль, почта и 2FA общих демо-аккаунтов,
  блокировка покупателей, настройки сайта, аналитики и курсов, импорт из Steam, рассылки, удаление медиа,
  рассылка и тексты бота, привязка Telegram, оплата Telegram Stars (`DemoGuard`, `DemoBotGuard`).
- **Демо-почта.** Письма сайта не уходят наружу — они в «Демо-почте» копии (ключ после покупки, подтверждения).
- **Оплата** — Stripe в тестовом режиме: карта `4242 4242 4242 4242`, любой срок и CVC.
- **Демо-ключи** `DEMO-XXXXX-XXXXX-XXXXX` — по 25 на товар и издание, с закупочной ценой (оживают отчёты).
- **Демо-аккаунты** `demo-admin` и `demo-buyer` показываются на странице приглашения вместе с паролями.
  Регистрация и «Забыли пароль» в демо выключены; страница аккаунта Keycloak у демо-аккаунтов только для чтения.
- **Поисковикам закрыт**: robots.txt «Disallow: /» и заголовок `X-Robots-Tag: noindex`.

## Каталог демо

`deploy/demo/catalog.json` — 70 узнаваемых игр по всем категориям, 110 DLC (у Batman: Arkham Knight и
Cities: Skylines II — все, у остальных до пяти самых дорогих, без роликов) и 5 программ из Steam. Даты «скоро
выйдет» в каждой копии считаются от её дня. Пакет собирается на стенде разработчика из его базы и медиа:

```bash
bash deploy/demo/build-demo-pack.sh            # → demo-pack/db.archive.gz (~1 МБ) и uploads.tar (~3,8 ГБ)
```

База стенда не меняется: пакет собирается в отдельной базе `TaleShopDemo`.

## Установка на сервер

Сервер может быть общим с другими сайтами: демо слушает только `127.0.0.1:8081`, а 80/443 держит системный
nginx сервера. Памяти нужно от 2 ГБ **и swap** (лимиты контейнеров — в `docker-compose.demo.yml`, в простое
демо по оценке займёт около 1,3 ГБ — уточнить замером после установки), диска — около 10 ГБ.

1. **Swap**, если его нет (2 ГБ):
   ```bash
   sudo fallocate -l 2G /swapfile && sudo chmod 600 /swapfile && sudo mkswap /swapfile && sudo swapon /swapfile
   echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab
   ```
2. **Код и `.env`** — как в [deploy.md](deploy.md) (шаги 1–3), плюс:
   ```bash
   COMPOSE_FILE=docker-compose.yml:docker-compose.prod.yml:docker-compose.demo.yml
   MONGO_DB=TaleShopDemo
   DEMO_ADMIN_PASSWORD=…        # публичные: их видят посетители демо
   DEMO_BUYER_PASSWORD=…
   STRIPE_SECRET_KEY=sk_test_…  # только тестовые ключи
   STRIPE_PUBLISHABLE_KEY=pk_test_…
   SMTP_HOST=localhost          # демо писем наружу не шлёт, но поле обязательно
   MAIL_FROM=demo@ваш-домен
   ```
   `BOT_TOKEN` — только отдельного демо-бота (не рабочего), или пусто.
3. **Запуск:** `docker compose up -d`.
4. **Каталог:** скопировать пакет на сервер и развернуть:
   ```bash
   scp -r demo-pack сервер:/opt/taleshop/          # с машины, где собран пакет
   bash deploy/demo/restore-demo-pack.sh demo-pack # на сервере
   ```
5. **Демо-аккаунты:** `bash deploy/demo/keycloak-demo-users.sh`.
6. **Системный nginx и сертификат** — по шагам в `deploy/demo/host-nginx.conf`.
7. **Stripe (тестовый режим):** вебхук `https://<домен>/api/payments/webhook` с событиями из deploy.md, его
   секрет — в `STRIPE_WEBHOOK_SECRET`.

Обновить каталог — собрать пакет заново и повторить шаг 4: песочницы старого шаблона удалятся.

## Если что-то пошло не так

- Демо-аккаунт заблокирован перебором паролей — Keycloak снимает блокировку сам через 15 минут.
- Копии заняты («All demo copies are taken») — `DEMO_MAX_SANDBOXES` в `.env`, если памяти хватает.
- Логи песочниц: `docker compose logs backend | grep -i "demo sandbox"`.
