# Вычитка переводов

Файлы `uk.md`, `pl.md`, `ru.md` — все строки витрины, кабинета и писем на одном языке рядом с английским оригиналом.
Сгенерированы автоматически из `tale-gameshop/src/locales/*.json` и `SuperBot.WebApi/Mail/MailTexts.*.cs`
(скрипт вычитки в истории задачи; повторная выгрузка — та же схема).

Как проверять: читать колонку перевода по разделам, замечания писать в самой строке таблицы или сразу править json/cs.
Подстановки `{{…}}`, `{0}` и теги `<b>` не трогать. После правок: `npm test` в `tale-gameshop` (проверка полноты словарей)
и `dotnet test SuperBot.WebApi.Tests --filter MailTextsTests`.
