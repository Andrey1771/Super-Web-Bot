# Tale Shop — кейс для портфолио

Материалы для профиля фрилансера: описание проекта (рус./англ.), сценарий видеообзора и список скриншотов.
Демо-сайт — [demo.md](demo.md). Ссылка на демо: `https://shop.<домен>` (появится после выкладки).

## Коротко (для карточки проекта)

**Tale Shop** — интернет-магазин цифровых ключей для игр и программ: витрина на четырёх языках, оплата картой,
моментальная выдача ключей, личный кабинет с кэшбэком, поддержка с ИИ-ассистентом, Telegram-бот с мини-приложением
и полноценная админка с импортом каталога из Steam и отчётами. Сделан с нуля, от архитектуры до выкладки на сервер.

**Стек:** React 19 + TypeScript, Tailwind 4 · .NET 10 (ASP.NET Core), MongoDB, Hangfire · Keycloak 26 (вход, 2FA) ·
Stripe (оплата, Stripe Tax) · Telegram Bot API (бот, Mini App, оплата Stars) · nginx, Docker Compose, GitHub Actions →
GHCR · более 1 000 автотестов бэкенда (xUnit, интеграционные на настоящей MongoDB) и 400+ тестов фронтенда (Jest).

## Что внутри

**Витрина**
- Каталог с фильтрами (жанры, цены, скидки, DLC, программы), поиск, сортировки; 4 языка (en/ru/uk/pl), несколько валют
  (сейчас USD и EUR) с курсами и ручными ценами, региональные цены.
- Карточка товара: галерея со скриншотами и трейлерами (HLS, в двух качествах), системные требования, издания,
  список DLC «как в Steam», отзывы с модерацией.
- Корзина и оплата через Stripe: сохранённые карты, промокоды, налог по стране покупателя (Stripe Tax).
- Ключ приходит сразу — в личный кабинет и письмом; гостевые покупки с подтверждением почты.
- Кэшбэк с уровнями, история начислений и сгорания; избранное, недавно просмотренное, рекомендации.
- Центр поддержки: база знаний, ИИ-ассистент в чате (с передачей живому специалисту), обращения.

**Аккаунт и безопасность** — вход через Keycloak, двухфакторная защита, управление сессиями, восстановление доступа
с проверкой администратором.

**Telegram** — бот с каталогом и мини-приложение магазина внутри Telegram с оплатой звёздами.

**Админка**
- Импорт игр, DLC и программ из Steam одной строкой appid: описания на всех языках, скриншоты, трейлеры, требования —
  всё скачивается к себе, без ссылок на Steam.
- Редактор товара с живым превью, управление DLC прямо из карточки игры, матрица цен по валютам.
- Склад ключей с закупочной ценой; отчёты: продажи за период, по играм, стоимость склада, воронка, каналы,
  брошенные корзины; Google Analytics.
- Новости и блог с редактором, рассылки, промокоды, «сделка недели», модерация отзывов, клиенты.
- Мониторинг сервисов (Stripe, почта, бот, LLM) с письмами о сбоях.

**Инфраструктура** — Docker Compose (MongoDB, Keycloak + Postgres, nginx, бэкенд, бот), лимиты частоты и памяти,
бэкапы с копией вне сервера, HTTPS, сборка образов в GitHub Actions.

**Демо-режим** (отдельная инженерная задача): каждый посетитель получает собственную копию магазина на сутки —
может менять цены, добавлять игры, покупать тестовой картой; его изменения не видит никто другой. Копии изолированы
на уровне базы и кэша, письма попадают в «демо-почту», действия, затрагивающие всех, — только просмотр.

## English version (for international profiles)

**Tale Shop** — a full-featured digital store for game and software keys, built end to end: a storefront in four
languages, card payments, instant key delivery, a customer account with cashback, AI-assisted support, a Telegram bot
with a Mini App, and a complete admin panel with Steam catalog import and sales reports.

- **Storefront:** filtered catalog, multi-currency pricing, product pages with HLS trailers and DLC lists, Stripe
  checkout with saved cards and Stripe Tax, instant key delivery by email and in the account, tiered cashback.
- **Support:** knowledge base, AI chat assistant with hand-off to a human agent, tickets.
- **Admin:** one-line Steam import (games, DLC, software — all media self-hosted), live product preview, key inventory
  with purchase costs, sales / inventory / funnel reports, CMS for news, newsletters, promo codes, service health alerts.
- **Live demo with personal sandboxes:** every visitor gets an isolated 24-hour copy of the store (own database and
  cache), so clients can try the admin panel and make test purchases without affecting anyone else.
- **Stack:** React 19 + TypeScript, .NET 10, MongoDB, Keycloak, Stripe, Telegram Bot API, nginx, Docker,
  GitHub Actions; 1,000+ backend and 400+ frontend automated tests.

## Сценарий видео (5–7 минут)

Записывать на демо-сайте в своей копии, окно браузера 1440×900, полоску «Демо» свернуть до значка.

| # | Время | Что показать | Что сказать |
|---|---|---|---|
| 1 | 0:00–0:30 | Главная: баннер, разделы, новинки | «Магазин цифровых ключей, сделан с нуля — от витрины до админки и сервера» |
| 2 | 0:30–1:15 | Каталог: фильтр по жанру и цене, «только DLC», поиск; переключить язык и валюту | Четыре языка, доллары и евро, региональные цены |
| 3 | 1:15–2:00 | Карточка игры с трейлером и DLC (Cities: Skylines II или Batman: Arkham Knight) | Медиа хранятся на своём сервере, трейлеры — потоком |
| 4 | 2:00–3:00 | В корзину → оплата тестовой картой 4242… → страница «ключ выдан» → ключ в кабинете → письмо в «Демо-почте» | Оплата через Stripe, ключ приходит сразу |
| 5 | 3:00–3:30 | Кабинет: кэшбэк за покупку, уровень, история | Программа лояльности |
| 6 | 3:30–4:00 | Поддержка: вопрос ИИ-ассистенту («где мой ключ?») | ИИ отвечает по базе знаний и передаёт живому специалисту |
| 7 | 4:00–5:15 | Админка: дашборд → импорт игры из Steam → редактор с превью → DLC → цены | Каталог наполняется из Steam за минуты |
| 8 | 5:15–6:00 | Отчёты: продажи, стоимость склада, воронка | Ключи с закупочной ценой — маржа считается сама |
| 9 | 6:00–6:30 | Telegram: бот и мини-приложение | Магазин доступен и внутри Telegram |
| 10 | 6:30–7:00 | Полоска «Демо»: «Начать заново», демо-почта | «Откройте демо по ссылке — у вас будет своя копия магазина на сутки» |

Импорт из Steam в демо отключён (общие файлы медиа) — для сцены 7 записывать на стенде разработчика.

## Скриншоты для профиля

1. Главная (светлая тема, 1440 px).
2. Каталог с открытыми фильтрами.
3. Карточка игры с трейлером и списком DLC.
4. Оплата (форма Stripe с тестовой картой).
5. Личный кабинет: заказ с ключом и кэшбэк.
6. Чат поддержки с ответом ИИ.
7. Админка: дашборд.
8. Админка: импорт из Steam и редактор товара с превью.
9. Отчёт о продажах.
10. Мобильная версия витрины (375 px).
